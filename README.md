## Descripción del proyecto

Este repositorio contiene la formalización de la **disciplina de Requisitos**
del Proceso Unificado (UP), modelada con **SPEM 2.0** y la herramienta
**EPF Composer 1.5.2**, como parte del Laboratorio 1 del curso.

El proceso cubre las cuatro fases de UP (Inicio, Elaboración, Construcción
y Transición) e incluye:

- 4 roles: Analista de Sistemas, Especificador de Requisitos, Revisor de
  Requisitos y Stakeholder.
- 7 tareas.
- 10 productos de trabajo (Artifact, Deliverable y Outcome).
- 6 guías (plantilla, ejemplo, checklist, tool mentor, directriz y concepto).
- 3 patrones de capacidad reutilizables.

## Cómo abrir el modelo en EPF Composer

1. Instalar **EPF Composer 1.5.2** (requiere JRE de 32 bits).
2. Abrir la aplicación → `File → Open Method Library`.
3. Seleccionar la carpeta `BibliotecaUP/` de este repositorio.
4. El proceso se encuentra en:
   `PluginRequisitosUP → Processes → Delivery Processes → disciplina_requisitos_up`.
