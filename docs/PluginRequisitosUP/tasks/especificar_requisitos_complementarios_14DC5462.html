Task: Especificar Requisitos Complementarios
Captura y documenta los requisitos no funcionales del sistema (rendimiento, seguridad, usabilidad, soporte) y las restricciones globales siguiendo el modelo FURPS+.
Disciplines: Requisitos

        Steps
        Identificar requisitos por categoría (usabilidad, fiabilidad, rendimiento, soporte y restricciones).

        Asociarlos a casos de uso cuando aplique.
        Validarlos con los stakeholders.
