Checklist: Lista de comprobación de requisitos
Criterios de calidad para revisar requisitos.
Relationships
Related Elements
  • Informe de Revisión de Requisitos
  • Revisar Requisitos
Main Description
  • Cada requisito tiene un identificador único.
  • Está redactado sin ambigüedad.
  • Es verificable o medible.
  • Es trazable a una solicitud de un stakeholder.
  • No contradice otros requisitos.
  • Todos los actores están identificados.
  • Cada caso de uso tiene flujo básico, flujos alternos, precondiciones y postcondiciones.
  • Los términos del dominio están en el Glosario.
  • Los requisitos no funcionales están cuantificados.
  • Los requisitos están priorizados.
