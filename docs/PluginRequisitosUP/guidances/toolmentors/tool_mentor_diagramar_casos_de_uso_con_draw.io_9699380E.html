  • Identificar Actores y Casos de Uso
Main Description
  1. Abrir diagrams.net y crear un diagrama en blanco.
  2. Dibujar un rectángulo como frontera del sistema.
  3. Agregar los actores (figura de persona) fuera del rectángulo.
  4. Agregar los casos de uso (elipses) dentro.
  5. Unir actores y casos de uso con asociaciones. Usar «include» y «extend» solo cuando aporten.
  6. Exportar como PNG o SVG y adjuntarlo al Modelo de Casos de Uso.
